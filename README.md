# Boiyk Store 🛍️

Project latihan membangun website e-commerce menggunakan HTML dan CSS. Dibuat sebagai bagian dari proses belajar front-end development.

## 📋 Tentang Project

Boiyk Store adalah tampilan (landing page) toko online sederhana yang dibangun dari nol untuk mempraktikkan dasar-dasar HTML dan CSS, mulai dari struktur halaman, styling, hingga layout responsif.

## ✨ Fitur / Section

- **Navbar** — navigasi utama website
- **Hero Section** — tampilan banner/pembuka yang menarik perhatian
- **Products** — daftar produk yang dijual
- **About** — informasi mengenai toko
- **Footer** — informasi tambahan dan penutup halaman

## 🛠️ Teknologi yang Digunakan

- HTML5
- CSS3

## 🚀 Cara Menjalankan

1. Clone repository ini
   ```bash
   git clone https://github.com/RBoik/project-e-commerce.git
   ```
2. Buka folder project
   ```bash
   cd project-e-commerce
   ```
3. Buka file `index.html` di browser
